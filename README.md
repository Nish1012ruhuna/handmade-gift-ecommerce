GIFTORA – Handmade & Personalized Gifts

GIFTORA is a modern e-commerce website designed for a handmade and personalized gift shop. The website allows customers to explore different gift products, search and filter products by category, view product details, add products to a shopping cart, and proceed to checkout.

The main purpose of GIFTORA is to provide customers with a simple, attractive, and convenient way to discover and purchase unique handmade and personalized gifts for birthdays, anniversaries, weddings, graduations, and other special occasions.



Project Overview
GIFTORA provides an online platform for selling handmade and customized gifts. Customers can browse products such as greeting cards, resin keychains, gift boxes, candles, wooden gifts, photo frames, and customized cakes.

The website has been designed with a clean and elegant interface using a soft, natural color scheme that matches the handmade gift concept.
